# Мой Дом — Законы

Центральный источник законов для «Мой Дом — Правовой Ассистент».

## Структура

- `manifest.json` — версия и список файлов
- `laws/` — документы и статьи

## Документы

1. Конституция РФ
2. УК РФ
3. УПК РФ
4. КоАП РФ
5. Трудовой кодекс РФ
6. Дорожный кодекс Нижегородской области
7. ФКЗ о «Закрытых и Охраняемых территориях»

При изменении закона увеличивайте `dataVersion` в `manifest.json`.

Это игровой справочник для RP-сервера.
